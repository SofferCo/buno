# שולחן משפחתי — פרוטוטייפ

מוקאפ אינטראקטיבי של אפליקציה לניהול סבב שבתות וחגים בין הצדדים של המשפחה.
**זו לא אפליקציית buno** — היא יושבת כאן כי `design-export/` היא תיקיית המוקאפים
של ה‑repo. אין לה חיבור לקוד ב‑`src/`, ל‑Supabase או ל‑build.

## איך פותחים

```
open design-export/shulchan/index.html
```

קובץ עצמאי אחד (~270KB). הכול רץ בדפדפן, בלי שרת ובלי התקנה. הפונטים נטענים
מ‑Google Fonts, אז בלי רשת הטיפוגרפיה תיפול ל‑system font — התצוגה עצמה עובדת.

## איך עורכים

`index.html` **נבנה** — לא לערוך אותו ידנית. עורכים את `src/` ומריצים:

```
node design-export/shulchan/build.mjs
```

| קובץ | מה יש בו |
| --- | --- |
| `src/template.html` | כל ה‑markup של המסכים. תגיות `<sc-if>` / `<sc-for>` ו‑`{{ ... }}` נקשרים לערכים שהסקריפט מחזיר |
| `src/dc-script.js` | כל הלוגיקה והסטייט — מנוע הסבב, דאטת הדוגמה, פורמט תאריכים עבריים, ייצוא ICS |
| `src/props.json` | props שניתנים לעריכה מהקנבס (כרגע `showBirthdays` בלבד) |
| `src/vendor/` | React 18, ReactDOM ו‑dc-runtime. לא לערוך — קוד צד שלישי |

## מה יש בפרוטוטייפ

- **כניסה** — Google או magic link, כולל כניסה דרך הזמנה מבית קיים
- **אונבורדינג בן 4 שלבים** — שמות הזוג, שני הצדדים והבתים בכל צד, היסטוריית חגים, אנשים וימי הולדת
- **האפליקציה** — טאבים לוח / עדכונים / הרשת, ותצוגת זוג מול תצוגת בית
- **מנוע הסבב** — 6 חגים (ערב ר״ה, סעודה מפסקת, סוכות, חנוכה, ליל הסדר, שבועות) עם היסטוריה לכל זוג, איזון אוטומטי בין הצדדים, ו‑override ידני לתאריך בודד
- **פר‑אירוע** — RSVP עם הערה, רשימת מגיעים, ״מה מביאים״, סקרים, ״לא מארחים בתאריך הזה״, ייצוא ICS ושיתוף במייל
- **תאריכים עבריים** — דרך `Intl` עם לוח `he-u-ca-hebrew`; ימי הולדת בלוח עברי או לועזי
- דאטת דוגמה: 3 בתים, 6 זוגות, טווח ספטמבר 2026 – אוגוסט 2027

הכול in‑memory. אין persistence ואין רשת — רענון מאפס את הכול.

## מקור

יוצא מ‑Claude Design כ‑bundle יחיד של 4.3MB שפורק את עצמו בדפדפן, שמתוכו כ‑3.5MB
היו 50 קובצי woff2 מוטמעים כ‑base64. כאן הפונטים נטענים מהרשת ורק ה‑runtime מוטמע,
כדי שהמקור יהיה קריא ב‑diff וניתן לעריכה ידנית.

הערה: `dc-runtime` עושה `fetch` על `location.href` בטעינה (hot reload). מעל `file://`
זה נחסם ב‑CORS ומדפיס שגיאה לקונסול — הוא עטוף ב‑`catch` ריק ולא משפיע על כלום.
